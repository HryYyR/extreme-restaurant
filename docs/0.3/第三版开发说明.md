## 对照优化项

1. **场景字模糊**：设施图形可以按世界格缩放，但名称在恢复到屏幕坐标后以原生14—18字号绘制，附半透明深色底；人物的像素精灵单独缩放，等餐圆圈和头顶/脚下字不再先绘成10px再整体拉大。PC窗口使用不整体拉伸字体的画布模式，1440×900和1100×720都有原生UI回归。
2. **稀有 / 特别客效果**：通用信息框从客人配置派生描述。博主显示金币倍率、基础声望；大胃袋显示金币倍率；霸王餐为0金币；老人有选菜/用餐时间倍率；地痞有等餐扣分周期、总耐心倍率。文本随配置而变，不借用固定介绍冒充规则。
3. **夜晚0金币与声望**：顶部将今日收入、持有金币、当前声望拆成三张标签卡。夜晚今日收入重新为0$属正常，金币卡仍显示真实余额，声望卡始终显示可花数值。结算后进入下一晚也有回归断言。
4. **采购处与厨师肖像**：显示名由老虎机换成采购处（内部ID slot不必随UI改名）；头像根节点提升到卡片前景，精灵帧仍在Avatar的低层，以便头顶状态不被人像遮挡。原生截图像素检查实际找到头像肤色像素，而不仅检查资源存在。
5. **逐件纵向购买**：右侧纵向三张商品卡，每张自己的购买按钮。菜谱展示基础价值、当前品质、普通客估价、现有烹饪Buff下的实际每锅秒数及每锅产量；Buff展示单层效果、持续时间、当前与购买后的层数 / 剩余营业日。右区在小窗口可滚动，购买和菜单替换事务仍按旧规则。
6. **现代餐厅**：由12×10扩大为24×16格，冷色厨房、玻璃内隔断、两条通道、暖色用餐区与侧翼采购区。墙体不能摆家具，所有设施交互点和岗位站位可达。初始3厨师、5服务员、12餐桌；临时上限12厨师、18服务员、36餐桌。初始角色分散在工作区而非重叠。路径校验改为一次区域遍历，减少大地图反复全图寻路。

## 工程入口

- data/chapter.json：分周人数、24×16格初始布局和3/5/12编制。
- scripts/core/layout.gd：内墙阻挡、道路与开店前可达性。
- scripts/core/simulation.gd：按岗位站位生成员工、单日模拟及房租。
- scripts/ui/world_view.gd：厨房/用餐区分区、家具和场景中文字。
- scripts/visuals/actor_view.gd：像素人物精灵缩放与不缩放文字。
- scripts/ui/main.gd：三项资源卡、稀有信息框、纵向采购和厨师肖像。
- tests/test_suite.gd、tests/ui_test.gd：规则与原生GUI回归；原始日志位于 .local。
