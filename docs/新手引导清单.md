# 阿禾的新手引导

## 实施清单

- [x] 通用角色气泡支持署名、正文、选项和自动消失。地图上的气泡跟随说话者，窗口中的气泡可以附带角色头像。
- [x] 首次进店时，前厅服务员阿禾招手。玩家可跟随她认识订单口、出餐口和本章的开局菜，也可选择「我自己逛」。
- [x] 用真实营业事件演示点单、端盘和收款。读点单气泡时暂停经营时钟，查看客人或选择继续后恢复。玩家拖动、滚轮缩放、键盘平移或复位均可接管镜头。
- [x] 首次日报按实际诊断讲解等待环节，提供地图定位，解释三星。首次午市预告随章节日历出现。
- [x] 夜晚按实际条件介绍采购、满菜单替换、声望升级和新家具摆放。地块按顺序、开放日和闪星价格讲解。展廊购买成功后才介绍获赠的铜摆钟。
- [x] 同一晚最多一次主动镜头提示。缴租优先于扩建，其余说明留到玩家进入相应设施。
- [x] 已学步骤与跳过选择单独保存，两章共用。设置中的「再听阿禾讲一遍」可以在当前进度重听。
- [x] 自动检查首次进店、镜头接管、真实营业事件、读档和日结确定性。

## 后续给客人添加台词

在表现层拿到当前地图和客人 ID 后即可调用。员工使用 `s_<员工 ID>`，营业中的客人使用 `g_<客人 ID>`。夜晚的第一位预备服务员为 `preview_waiter_0`。

```gdscript
world.say("g_%d" % guest.id, "客人", "我的菜快好了吗？", 4.0)
```

最后一个数值是屏幕显示秒数。普通气泡不拦截点选，也不会暂停营业。多名角色可以同时说话。传入负时长可改为由调用方关闭，返回值支持 `add_choice(标题, 回调)` 和 `dismiss()`。抱怨的触发条件和频率应放在调用方，例如首次产生等餐扣分时说一次。

气泡样式在 `scripts/ui/speech_bubble.gd`，教程顺序和台词在 `scripts/ui/restaurant_guide.gd`。价格、营业日和诊断使用当前章节及当天报告。教程进度使用独立的 `tutorial_progress.json`，不改变餐厅检查点版本。

## 验证

在项目目录运行以下回归。

```powershell
powershell -ExecutionPolicy Bypass -File tools/run_game.ps1 -Mode tutorial-test
```

测试使用独立测试存档。正常体验请从章节选择进入餐厅。
